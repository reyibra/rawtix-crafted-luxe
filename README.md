# Rawtix: Brand Blueprint

Saya ingin Anda bertindak sebagai **Lead Product Strategist, UX Architect, dan Technical Planner** untuk proyek website e-commerce berbasis web milik brand fashion **rawtix.id**.

## TASK

Saya ingin Anda membuat **planning tahap awal yang sangat tajam, terukur, dan terstruktur** untuk website e-commerce rawtix.id, dengan acuan visual dan alur dari referensi yang saya unggah.  

**Jangan menulis kode dulu. Jangan langsung generate halaman dulu. Fokus hanya pada planning awal yang matang agar implementasi berikutnya minim revisi.**

Tujuan utama planning ini:

1. Menerjemahkan identitas brand rawtix.id ke dalam website e-commerce premium.

2. Mengadopsi pola UX/UI utama dari brand referensi **Televisi Star Catalog**.

3. Menyusun fondasi proyek secara lengkap dengan kerangka:

   - **Planning**: problem, app flow, core features

   - **Frontend**: UI, navigation

   - **Backend**: database, API endpoints

4. Menyiapkan blueprint implementasi yang siap dipakai untuk tahap build berikutnya di Lovable.

## REFERENCE

Saya ingin website rawtix.id **bukan sekadar meniru**, tetapi **mengadopsi struktur rasa, ritme visual, dan pola UX** dari Televisi Star Catalog, lalu disesuaikan dengan identitas rawtix.id.

### Berikut reverse-engineered blueprint dari referensi yang WAJIB Anda pahami:

**Always**

- Always gunakan arah visual **dark, premium, minimal, editorial, fashion-forward**.

- Always jadikan **produk dan brand** sebagai pusat perhatian, bukan ornamen UI.

- Always pertahankan **navigasi yang sederhana, ringan, dan rapi**.

- Always gunakan **grid katalog yang bersih** dan mudah discan.

- Always pertahankan pengalaman belanja bertahap: **browse → choose options / quick view → cart → checkout**.

- Always buat UI terasa **eksklusif, independen, crafted, dan tidak generik**.

- Always pikirkan brand rawtix.id sebagai **fashion label**, bukan toko online massal.

- Always prioritaskan pengalaman desktop dulu, lalu pastikan responsif ke mobile.

- Always siapkan pondasi untuk **kategori produk, status stock, sold out, preorder, dan checkout Indonesia**.

- Always jaga logo rawtix.id tetap menjadi anchor identitas visual.

**Never**

- Never gunakan gaya UI marketplace yang ramai, norak, atau terlalu promosi.

- Never gunakan warna-warna cerah yang merusak nuansa monokrom brand.

- Never gunakan kartu produk yang terlalu playful atau ecommerce-template look.

- Never buat navigasi terlalu kompleks di tahap awal.

- Never membuat halaman terlihat seperti website fashion murah atau dropship generik.

- Never menambahkan fitur yang tidak relevan dengan MVP awal.

- Never abaikan flow cart dan checkout.

- Never langsung masuk ke coding tanpa planning yang solid.
